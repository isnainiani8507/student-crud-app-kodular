# Student Data Management App

Aplikasi mobile sederhana untuk mengelola data mahasiswa yang dikembangkan menggunakan Kodular.

## Overview
Aplikasi ini dikembangkan sebagai bagian dari tugas mata kuliah Pemrograman Mobile untuk mengimplementasikan fungsi CRUD (Create, Read, Update, Delete) dasar dalam aplikasi mobile menggunakan Kodular.

## Features
- Menambahkan data mahasiswa
- Menampilkan data mahasiswa
- Mengedit data mahasiswa
- Menghapus data mahasiswa
- Antarmuka mobile sederhana

## Tools & Technologies
- Kodular
- PHP
- MySQL

## Purpose
Proyek ini dibuat untuk meningkatkan pemahaman tentang pengembangan aplikasi mobile dan konsep manajemen data menggunakan Kodular.
